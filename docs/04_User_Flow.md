# User Flow

## Browse (Home — playdate-first)

1. Open **홈** → see Playdate CTA, upcoming playdates, popular/recent posts, category chips, filtered feed
2. Optional: filter **전체 / 플레이데이트 / 육아톡** or tap a category chip
3. Tap Playdate or Post card → Detail → back
4. On Playdate detail: join / leave / ownership / full states (local)

## Create

**만들기** tab → **플레이데이트 만들기** or **글 작성하기** → fill form → save

- New items appear on Home via existing providers/repositories (local mock)
- New items initialize engagement counts at 0
- Post form includes category selection

Hero CTA on Home also opens Playdate create.

## Profile

프로필 tab → view mock profile info

## Navigation note

Long-term bottom nav may expand (홈 · 플레이데이트 · 만들기 · 알림 · 프로필). MVP keeps three **functional** tabs only — no dead destinations.
