# Product Principles

1. **Community first** — Groups are the primary product; Event Announcements live inside Groups.
2. **Trust before logistics** — membership and discussion enable offline meetups.
3. **Simple > Complex** — ship useful local flows before heavy infrastructure.
4. **Real connections > Features** — optimize for belonging and offline activities among members.
5. **Scope discipline** — if it is not in `MVP_SPEC.md` / the active phase, do not build it yet.
6. **Consistent language** — prefer Group / Post / Event Announcement; treat Playdate as legacy code terminology.
